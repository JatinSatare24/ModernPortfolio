# Jatin Satare, Portfolio

Next.js (App Router) + TypeScript + Tailwind CSS + Framer Motion + Lenis. Contact form via Resend.

All content lives in `content/` and `public/`. See **[CONTENT_GUIDE.md](./CONTENT_GUIDE.md)** for how to update it.

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production build
```
